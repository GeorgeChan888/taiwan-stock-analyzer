🏦券商分點主力動向彙整2026/04/29 盤後

以下統計各標的近 5 日主力券商分點累計買賣超張數， 「主力積累」為買超分點數 ≥ 賣超分點數且淨買超 > 1,000 張； 紅色為買超，綠色為賣超（台股慣例）。

代碼名稱 買超分點數賣超分點數 主力淨買(張)集中度(%) 前5大分點動向判斷

⚠ 集中度說明： 集中度 = 前5大分點買超張數 ÷ 總買超張數 × 100%。 數值越高代表籌碼越集中在特定主力手中，通常視為強勢主力控盤的訊號， 但也需注意過度集中時的出貨風險。集中度 > 60% 為高度集中。

// 計算主力集中度
function calcConcentration(brokers) {
  const sorted = brokers.sort((a,b) => b.buy - a.buy);
  const top5   = sorted.slice(0,5).reduce((s,b) => s + b.buy, 0);
  const total  = brokers.reduce((s,b) => s + b.buy, 0);
  return (top5 / total * 100).toFixed(1) + '%';
}

// 回傳結構
// { 持股分級: "1-999", 人數: 45821, 股數: 18234521, 占比: "12.34%" }
// 分級：1-999股、1000-5000、5001-10000、...
//       400001-800000、800001以上（大戶 > 1000張）

// 計算大戶比例
function calcWhaleRatio(grades) {
  const whales = grades
    .filter(g => parseInt(g.持股分級) > 400000)
    .reduce((s,g) => s + parseFloat(g.占比), 0);
  return whales.toFixed(2) + '%';
}
